# АРХИВ 13 — Охота на преступника

Интерактивный детективный квест, который запускается в браузере. Игрок проходит 10 заданий, собирает улики, изучает досье шести сотрудников и пытается определить, кто проник в хранилище.

## Содержимое

- `index.html` — вся игра: разметка, оформление и JavaScript.
- Отдельные изображения и аудиофайлы не требуются: портреты подозреваемых нарисованы средствами SVG, а атмосферный звук создаётся браузером.

## Как запустить локально

1. Скачайте `index.html`.
2. Откройте файл двойным щелчком в современном браузере (Chrome, Firefox, Edge или Safari).
3. Нажмите **«Начать расследование»**.
4. Для включения фоновой атмосферы нажмите **«Включить атмосферу»**. Браузер может разрешить звук только после нажатия кнопки.

Для прохождения нужен интернет только при создании QR-кода: изображение QR загружается с внешнего сервиса. Вставьте полную ссылку на песню, начинающуюся с `https://` или `http://`.

## Публикация через GitHub Pages

1. Войдите в [GitHub](https://github.com/) и создайте новый репозиторий.
2. Назовите его, например, `archive-13-game`. Для простой публикации выберите **Public**.
3. Загрузите `index.html` в корневую папку репозитория.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Укажите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
7. Дождитесь публикации. Адрес сайта появится в разделе **Settings → Pages** и обычно будет иметь вид:

   `https://ВАШ-ЛОГИН.github.io/archive-13-game/`

8. Откройте ссылку самостоятельно и проверьте прохождение на телефоне и компьютере, прежде чем отправлять её подруге.

## Управление

- Используйте кнопки и поля на экране для ответов.
- Во втором задании перемещайте курсор или палец по комнате, чтобы двигать луч фонарика; нажмите на ракушку, когда найдёте её.
- В задании с очисткой фотографии нажмите на все девять участков.
- В финале сравните улики с карточками подозреваемых и введите имя и фамилию.

## Важно

- Это небольшая браузерная игра без сервера и базы данных. Прогресс не синхронизируется между устройствами и не сохраняется после перезагрузки страницы.
- Портреты подозреваемых в текущей версии — стилизованные SVG-иллюстрации, а не фотографии реальных людей.
- Фоновая атмосфера генерируется Web Audio API и не является отдельной музыкальной записью.
- QR-код создаётся внешним сервисом `api.qrserver.com`; для этой функции требуется подключение к интернету.
- Не размещайте в игре личные данные, которые не хотите публиковать.

## Настройка финальной песни

В текущей версии игрок сам вводит ссылку на песню на финальном экране. Если хотите заранее указать конкретную песню, измените текст и логику обработчика кнопки `Создать QR-код` в `index.html`.
